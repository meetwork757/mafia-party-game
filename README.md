# Mafia Party Game

Simple web-based Mafia game for friends.

## Features
- Enter username
- Min 5, Max 10 players
- Random roles: 2 Mafia, 1 Savior, rest Citizens
- Private role flashcard (name on top, role below)
- Chat box for all players
- Voting section to vote who is the mafia

## How to get the link
1. Go to repo Settings > Pages
2. Source: Deploy from a branch, Branch: main, Folder: / (root)
3. Save. Wait a minute.
4. Your game link: https://meetwork757.github.io/mafia-party-game/

## How to play
Everyone opens the link on phone or computer, enters username, joins, clicks Ready.
Game starts only when at least 5 players are ready.
Roles are private to each player.
Works on iPhone and Android.

Note: Current version is a local demo (state is per browser). For true real-time sync across friends' devices, integrate Firebase Realtime Database (free tier).
